================================================================

一、字号：为什么是 4.8 而不是 6.0
----------------------------------------------------------------
以「单个绘图区宽度相同」为基准，量了参考图 SI Figure S4（Predictive-scale
distributions 九宫格，文件 20261024_final_figures_svg/si/FigureS4.svg）：

  参考图：刻度数字 8.0 pt，绘图区宽 211.00 pt  → 3.79 %（字体/绘图区宽）
  上一轮：刻度数字 12.0 pt，绘图区宽 125.569 pt → 9.56 %
  50 %  ：6.0 pt，同一绘图区          → 4.78 %（仍比参考宽 26 %）
  本轮  ：4.8 pt = 8.0 × 125.569/211.00 → 3.82 %  ← 采用

实测字高（600 dpi 像素计，同样的取墨阈值）：
  参考图 6.24 pt 字高 / 211.00 pt 绘图区宽 = 2.96 %
  本轮   3.60 pt 字高 / 125.569 pt 绘图区宽 = 2.87 %   比值 0.97
即与参考图一致（差 3 %，在抗锯齿取阈的误差内）。字体 Arial、常规字重。

二、随之收紧的间距与画布
----------------------------------------------------------------
  数字与轴的间距：y 方向由 6.50 pt 收到 5.08 pt（刻度 3 pt + 留白 2.08）；
                  x 方向基线由轴上 11.87 pt 收到 8.52 pt。
  留白 2.08 pt 是按参考图的 3.5 pt 留白 × 125.569/211.00 换算来的。
  画布：171.840 × 139.200 → 148.280 × 130.760 pt（四周留白 2.50 pt）。
  九个图仍共用同一个画布尺寸和同一个绘图区偏移 (19.66, 4.30) pt。

三、没变的东西（已逐项验证）
----------------------------------------------------------------
  · 绘图区 125.569 × 115.162 pt、长宽比例、位置不变；
  · 柱子：60 个分箱、计数、颜色 #6C92C3 / 边 #3D5E8D、线宽全部不变；
    「去掉文字后 600 dpi 逐像素比对，与上一轮差异 0 像素」；
  · 轴范围、刻度位置、刻度数值不变（与脚本+数据一致：x 最大偏差 0.0009 pt，
    540 根柱顶与 count/ylim 最大偏差 0.0011 pt）；
  · 刻度线保留（3 pt，向外），九个图横纵轴刻度线和刻度数字都在；
  · 仍然没有 Count、参数名、轴标题、图标题、子图编号。

五、放进 PPT 时请注意
----------------------------------------------------------------
画布变小了（171.84×139.20 → 148.280×130.760 pt），但绘图区尺寸没变。
按「原始大小」插入（即 148.280 × 130.760 pt）时，绘图区仍是原来的物理尺寸，
九张图的箱体位置和相互间距可以直接沿用上一轮的摆放，只要九张用同一个尺寸。
