## 修复的三类错误
1. **z 列 = d/sigma 被写成 d**：v2 `e2v2_inverse_mesh_sensitivity.csv` 的 `z` 列实为
   `d_mu_norm`（原样差），判据 flag 却用 `d/sig` 算——于是“per-param 最坏 |z|”表读了错误列，
   把**归一化原样差 ~0.04** 当成了 **0.04σ**。v3 拆为 `z_ref=d_mu_norm/σ_ref`（主判据 |z_ref|>0.1）
   与 `z_current=d_mu_norm/σ_current`（次），`sensitive_ref/cur` 分开。
2. **单参数 norm_to_log10 静默广播错误**：`norm_to_log10(np.array([x]))` 把 x 广播到全部 9 列后取
   `[0]` → 每个参数的 `mu_log10` 都被 mu_n 列的 scaler 换算（v2 列全部错误）。v3 逐列显式：
   `mu_log10[j]=mu_norm[j]*R[j]+Lmin[j]`；`σ_log10[j]=σ_norm[j]*R[j]`；
   `d_mu_log10[j]=d_mu_norm[j]*R[j]`；`mu_point_phys=10**mu_log10`（称“点估计”，不称物理均值）。
3. **容差/网格混淆**：v2 mesh_sensitivity 表把 tol 行也相对 ref 比（m0.25 的 tol 行会混入网格差）。
   v3 分表：mesh 表只含 mesh 行 vs ref；容差单独做**同网格** stol 直接配对。
