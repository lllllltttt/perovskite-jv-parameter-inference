## 科学判据状态：相邻档反演点估计漂移（新增、决定性）
此前 E2_inverse_repair 报的是"细档 vs **m=1 冻结参考**"的累计差 z_ref（最坏 rad_c 0.77、mu_p 0.61、
mu_n 0.51 …，0.3–0.7σ_ref）。本轮把它拆成**相邻档**（z_adj = 相邻两档点估计差 / σ_ref，同参考口径），
判断"网格还在动"还是"早已收敛、只是相对粗 m=1 有个偏移"：

| 档对 | max\|z_adj\| (σ_ref) | 中位\|z_adj\| | \|dμ_log10\| max (decade) | >0.1σ 格点数 / 54 |
|---|---|---|---|---|
| ref(m=1) → m0.35 | 0.644 | 0.104 | 0.145 | **28** |
| m0.35 → m0.25 | 0.062 | 0.0065 | 0.014 | 0 |
| m0.25 → m0.18 | 0.039 | 0.0050 | 0.009 | 0 |
| m0.18 → m0.125 | **0.021** | 0.0029 | 0.005 | 0 |

- 细链 m0.35→m0.25→m0.18→m0.125 三级相邻漂移 **0.062→0.039→0.021 σ_ref，单调递减**，
  **54 个格点（6 代表 × 9 参数）在每一级都无 >0.1σ** → 反演点估计在细链内**已收敛**，且收敛速度随
  网格细化加快。
- 反演对网格的全部敏感性集中在**单个 ref→m0.35 粗-细第一步**（28/54 >0.1σ，max 0.64σ_ref）。
  即冻结 m=1 参考与"已收敛细解"之间有一个粗网格**参考偏移**；越过第一步后细链自身不再显著移动。
- 因此对 E2 的**诚实解读**：冻结管线（m=1）的反演点估计坐落在离收敛细解 0.3–0.7σ_ref（物理量纲
  ≤0.10–0.48 decade）处——这是"冻结推理用的粗网格参考不代表收敛正演"的偏移，**不是**"网格持续
  不收敛"。细网格反演解本身可作为可靠收敛目标。

## 支持结论
- 正演（§四）：**器件指标与 ≤1 V 生成段数据已收敛**——三对全过判据、最后两档余量 ≫ 判据、
